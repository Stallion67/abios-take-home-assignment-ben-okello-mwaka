## 💡 About the Project

Provide a detailed explanation of what your project is, why it was created, and what problem it solves.

This is a **Node.js** application that serves as a simple project management tool, allowing users to create tasks, assign statuses, and track progress. We built it because existing tools were too complex for small team needs.

## ✨ Features

List the key functionalities and selling points of your project.

* **Task Creation:** Easily add new tasks with descriptions and due dates.
* **Status Tracking:** Move tasks between `To Do`, `In Progress`, and `Complete`.
* **User Authentication:** Secure login/logout using JWT.
* **Responsive UI:** Works great on desktop and mobile devices.
